# Sync conformance vectors

Generated by phibrowser-mac's own sync merge core, and replayed against the
C++ port by `test/model/sync_vectors_test.cc` (part of `test/model/run.sh`).
Do not edit by hand: every expected value is what the Swift production code
computed. `manifest.json` records the phibrowser-mac revision and the seed.
The format is documented in phibrowser-mac `Tests/SyncConvergence/VECTORS.md`.

Regenerate after the Mac's merge code changes (the harness needs a Swift
toolchain; on Linux, swift.org's release tarball works, see VECTORS.md):

```sh
cd ../phibrowser-mac   # at the revision to pin
SWIFT_PROTOBUF_PATH=/path/to/swift-protobuf \
SYNC_CONV_EMIT_VECTORS="$PWD/../phibrowser-win/test/sync-vectors" \
SYNC_CONV_VECTORS_ONLY=1 \
  bash build-scripts/test-sync-convergence.sh
```

`SWIFT_PROTOBUF_PATH` is a checkout of apple/swift-protobuf at the revision
phibrowser-mac's `Package.resolved` pins (1.38.1 at the time of writing).
